# 公文技能比武 · 备考工作台

依据《ChatGPT风格工作台UI设计系统V1.0》制作的完全离线刷题网页，收录324题（组）模拟训练内容。

## 题库构成
- 单选题：187道
- 判断题：100道
- 病文找错改错：14组
- 正式通知拟写：8道
- IOA系统实操：15项
- 两套60分钟模拟卷：每套30道单选、20道判断、1组病文改错、1篇通知拟写。

## 使用

直接双击 `index.html` 即可使用（同目录保留 `data.js`、`app.js`、`styles.css`、`tokens.css`），或者通过 GitHub Pages 静态托管访问。无 npm、CDN、服务器、第三方字体等依赖。

训练模块：学习总览、专项练习、模拟考试、实务训练、错题与收藏、冲刺计划、数据与设置。

答题记录保存在**当前浏览器的 localStorage**，不会自动同步到 GitHub、其他浏览器或设备。使用“数据与设置→导出备份”保存 JSON，换设备时用导入备份继续。

注意：模拟考试的客观题自动计分50分，主观题50分**人工自评**；不要将系统自动分数误认为比赛最终得分。试题与参考解析来自用户提供的配套Excel，属于模拟训练，**非官方试题**。

## 设计规范

来自上传的《ChatGPT 风格工作台 UI 设计系统 V1.0》：原始 `tokens.css`、中性配色、系统字体栈、240px侧栏、64px顶栏、36px按钮与输入框、12px卡片圆角、语义状态、移动端自适应、深色模式、键盘焦点、无远程资源。
